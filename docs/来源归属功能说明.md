# 来源归属功能使用说明

## 概述

聊天接口现已支持**来源归属**（Source Attribution）功能，在返回AI回答的同时，提供引用的RAG文档信息和联网查询结果，增强答案的可追溯性和可信度。

## 功能特性

### 1. RAG文档来源（`rag_sources`）

当AI回答基于知识库文档时，返回引用的文档片段信息：

**字段说明：**
- `rank` (int): 相关性排名（1-3）
- `doc_id` (str): 文档唯一ID
- `kb_id` (str): 知识库ID
- `content_snippet` (str): 文档内容摘要（最多200字符）
- `score` (float): 相关性评分（0.0-1.0，基于RRF融合算法）
- `chunk_index` (int, 可选): 文档分块索引

**示例：**
```json
{
  "rank": 1,
  "doc_id": "doc_12345abc",
  "kb_id": "kb_jewelry_tech",
  "content_snippet": "雕蜡工艺是传统首饰制作中的重要环节，通过精密雕刻蜡材形成首饰雏形...",
  "score": 0.8756,
  "chunk_index": 3
}
```

### 2. 联网查询来源（`web_sources`）

当AI回答包含实时网络信息时，返回引用的网页来源：

**字段说明：**
- `rank` (int): 相关性排名（1-5）
- `title` (str): 网页标题
- `url` (str): 来源URL
- `score` (float): 相关性评分（由Tavily API提供）

**示例：**
```json
{
  "rank": 1,
  "title": "北京天气预报 - 中央气象台",
  "url": "https://weather.example.com/beijing",
  "score": 0.9234
}
```

## API响应格式

### 标准聊天接口 (`/api/chat/message`)

**请求：**
```json
{
  "user_id": "user_123",
  "employee_id": "hutao",
  "query": "雕蜡工艺的基本原理是什么？",
  "context": {}
}
```

**响应：**
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "conversation_id": "conv_abc123",
    "session_id": "sess_xyz789",
    "answer": "雕蜡工艺是通过雕刻蜡模来制作首饰原型的传统技法...",
    "intent": "knowledge_query",
    "confidence": 0.92,
    "kb_used": ["kb_jewelry_tech"],
    "web_search_used": false,
    "sources": {
      "rag_sources": [
        {
          "rank": 1,
          "doc_id": "doc_12345",
          "kb_id": "kb_jewelry_tech",
          "content_snippet": "雕蜡工艺是传统首饰制作中的重要环节...",
          "score": 0.8756,
          "chunk_index": 3
        }
      ],
      "web_sources": []
    },
    "timestamp": "2025-12-19T10:30:00Z"
  }
}
```

### 流式接口 (`/api/chat/stream`)

在SSE流的**done事件**中包含sources信息：

```json
{
  "type": "done",
  "conversation_id": "conv_abc123",
  "confidence": 0.92,
  "kb_used": ["kb_jewelry_tech"],
  "web_search_used": false,
  "faq_matched": null,
  "sources": {
    "rag_sources": [...],
    "web_sources": [...]
  }
}
```

## 触发场景

### RAG文档来源

以下情况会返回RAG文档来源：

1. **知识库查询** - 用户问题匹配知识库内容
2. **FAQ匹配** - 虽然跳过RAG检索，但可能返回FAQ对应的文档来源（如果有关联）
3. **混合查询** - 同时使用RAG和联网查询时，两种来源都会返回

**特点：**
- 最多返回**前3条**最相关的文档片段
- 内容摘要自动截断至**200字符**
- 评分基于**RRF融合算法**（结合向量搜索和关键词搜索）

### 联网查询来源

以下情况会返回联网查询来源：

1. **实时查询** - 检测到天气、新闻、时间等实时信息需求
2. **RAG失败** - 知识库相关性评分低于0.6时的降级策略
3. **员工配置** - 数字员工启用了`web_search_enabled`功能

**特点：**
- 最多返回**前5条**网络搜索结果
- 包含页面标题、URL和相关性评分
- 由**Tavily API**提供搜索服务

## 配置选项

### 内容摘要长度

在 `chat.py` 的 `format_sources()` 函数中可配置：

```python
def format_sources(retrieved_docs: list, web_search_results: list, max_content_length: int = 200):
    # 调整 max_content_length 参数（默认200字符）
```

**建议值：**
- 移动端UI: 100-150字符
- 桌面端UI: 200-300字符
- 详细展示: 400-500字符

### 来源数量

当前硬编码限制：
- RAG来源: 前3条 (`retrieved_docs[:3]`)
- 联网来源: 前5条 (`web_search_results[:5]`)

如需调整，修改 `chat.py` 中的切片范围。

### 代码示例（React）

```tsx
interface SourceAttribution {
  rag_sources: RAGSource[];
  web_sources: WebSource[];
}

function SourcesDisplay({ sources }: { sources: SourceAttribution }) {
  return (
    <div className="sources-container">
      {sources.rag_sources.length > 0 && (
        <div className="rag-sources">
          <h4>📚 知识库参考</h4>
          {sources.rag_sources.map((src, idx) => (
            <div key={idx} className="source-card">
              <div className="source-header">
                <span className="rank">#{src.rank}</span>
                <span className="doc-id">{src.doc_id}</span>
                <span className="score">{(src.score * 100).toFixed(1)}%</span>
              </div>
              <p className="snippet">{src.content_snippet}</p>

        </div>

        <div className="web-sources">

  );
```

## 注意事项

### 1. 知识库名称缺失

⚠️ **已知限制**：当前RAG来源仅返回`kb_id`，不包含`kb_name`（知识库名称）。

**解决方案：**
- **后端方案**：在MongoDB中查询kb_name（增加延迟）
- **前端方案**：维护kb_id到kb_name的映射表
- **未来优化**：在ChromaDB元数据中预存kb_name

### 2. 文档标题/文件名缺失

⚠️ **已知限制**：文档块元数据中没有存储原始文件名或文档标题。

**当前显示**：仅显示`doc_id`（如"doc_12345abc"）

**改进建议**：
- 在文档上传时，将文件名存入ChromaDB元数据
- 在文档管理中允许设置文档标题

### 3. 内容截断

RAG来源的`content_snippet`默认截断至200字符。如果需要完整内容：

**选项A** - 增加截断长度（前端需适配）
**选项B** - 前端调用文档详情API获取完整内容
**选项C** - 提供"展开"按钮，点击时再加载

### 4. 性能影响

来源归属功能对性能影响极小：
- 数据已在RAG检索时获取，无额外查询
- 仅增加少量格式化处理（<1ms）
- 响应体积增加约1-2KB（取决于来源数量）
