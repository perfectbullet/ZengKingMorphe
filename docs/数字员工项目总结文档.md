## 一、项目背景与目标

### 1.1 项目定位

**数字员工（Digital Employee）**是一个企业级AI对话助手平台，旨在通过AI技术提升客户服务质量和效率。

### 1.2 核心目标

🎯 **提升Agent回答的准确性**，通过以下关键维度（更新版）：
1. **RAG知识库检索**：精准的向量检索 ✅ 最高优先级
2. **文档相关性评分**：LLM评分确保文档质量 ✅ 核心功能
3. **联网检索补充**：实时信息获取 ✅ 核心功能
4. **流式输出**：SSE流式响应提升体验 ✅ 核心功能

### 1.3 团队配置

- **团队规模**：4人小团队
- **角色分工**：
  - 1名前端工程师（Vue.js）
  - 1名AI研发工程师（Python AI引擎）← **您的角色**
  - 2名其他工程师

### 1.4 技术栈选型（更新版）

| 技术类别 | 选型方案 | 用途 |
|---------|---------|------|
| **工作流编排** | LangGraph | 对话流程状态机 |
| **文档数据库** | MongoDB | 对话记录、知识文档 |
| **向量数据库** | Chroma | 向量检索 ✅ 核心 |
| **Web框架** | FastAPI | REST API + SSE流式 ✅ |
| **LLM集成** | OpenAI API | 答案生成、文档评分 |
| **联网检索** | Tavily API | 实时信息搜索 ✅ 新增 |
| **Java集成** | HTTP API | FAQ、敏感词数据 ✅ 新增 |
| **容器化** | Docker Compose | 服务编排 |

### 2.2 核心需求补充（更新版）

基于原始需求，我们优化和补充了以下关键需求：

#### 对话引擎模块（简化优化）
1. **接口简化**：仅REST API + SSE流式，移除WebSocket
2. **流式优化**：仅支持SSE格式，移除移动端优化
3. **上下文管理**：简化为最近5-10轮对话
4. **敏感词拦截**：Java接口集成，无需AI开发CRUD

#### 知识库系统（核心功能强化）✅
1. **RAG文档库**：文档上传、解析、分块、向量化（最高优先级）
2. **文档相关性评分**：LLM对检索文档打分（0-1分），阈值0.6
3. **联网检索**：文档相关性低或实时性问题时触发（Tavily API）
4. **FAQ问答库**：Java平台提供接口，AI侧调用并向量化

**Java平台接口规范**：
- FAQ查询接口：`GET /api/java/faq/list`
- FAQ详情接口：`GET /api/java/faq/{faq_id}`
- FAQ变更通知（Webhook）：`POST /api/ai/faq/sync-notify`
- FAQ批量同步：`GET /api/java/faq/sync-all`
- 敏感词查询：`GET /api/java/sensitive-words/list`
- 敏感词变更通知：`POST /api/ai/sensitive-words/sync-notify`

#### 意图识别模块（大幅简化）
1. **简化为二分类**：实时信息类vs知识库查询类
2. **基于规则匹配**：关键词检测，无需LLM
3. **移除功能**：实体提取、槽位填充、多意图处理

#### 联网检索功能（核心新增）✅
1. **触发条件**：
   - 知识库文档相关性 < 0.6
   - 问题包含实时性关键词（天气、新闻、股价等）
2. **实现方式**：Tavily/SerpAPI
3. **结果处理**：Top 3-5条搜索结果 + 知识库文档混合生成答案

class ConversationState(TypedDict):
    user_query: str

    intent: str

    final_answer: str
    confidence: float

def build_conversation_graph():

    graph.add_node("validate_input", validate_input)
    graph.add_node("recognize_intent", recognize_intent)
    graph.add_node("hybrid_search", hybrid_search)
    graph.add_node("generate_answer", generate_answer)
    
    # 添加边
    graph.add_edge("validate_input", "recognize_intent")
    graph.add_edge("recognize_intent", "hybrid_search")
    graph.add_edge("hybrid_search", "generate_answer")

### 5.3 混合检索实现

```python
async def hybrid_search(query: str, top_k: int = 5) -> List[Dict]:
    """混合检索"""
    # 1. 并行执行向量和关键词检索
    vector_results, keyword_results = await asyncio.gather(
        vector_retrieval.search(query, top_k=20),
        keyword_retrieval.search(query, top_k=20)
    )
    
    # 2. RRF融合
    merged = rrf_fusion(vector_results, keyword_results, k=60)
    
    # 3. 返回Top K
    return merged[:top_k]

def rrf_fusion(vector_results, keyword_results, k=60):
    """RRF算法"""
    scores = {}
    for rank, item in enumerate(vector_results):
        scores[item["id"]] = scores.get(item["id"], 0) + 1/(k + rank + 1)
    for rank, item in enumerate(keyword_results):
        scores[item["id"]] = scores.get(item["id"], 0) + 1/(k + rank + 1)
    
    return sorted(scores.items(), key=lambda x: x[1], reverse=True)
```
