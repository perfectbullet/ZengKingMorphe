## 一、项目背景与目标

### 1.1 项目定位

**数字员工（Digital Employee）**是一个企业级AI对话助手平台，旨在通过AI技术提升客户服务质量和效率。

### 1.2 核心目标

🎯 **提升Agent回答的准确性**，通过以下三个关键维度：
1. **知识库召回**：精准匹配相关知识
2. **意图理解**：准确识别用户意图
3. **答案生成**：高质量内容生成

### 1.3 团队配置

- **团队规模**：4人小团队
- **角色分工**：
  - 1名前端工程师（Vue.js）
  - 1名AI研发工程师（Python AI引擎）← **您的角色**
  - 2名其他工程师

### 1.4 技术栈选型

| 技术类别 | 选型方案 | 用途 |
|---------|---------|------|
| **工作流编排** | LangGraph | 对话流程状态机 |
| **文档数据库** | MongoDB | 对话记录、知识文档 |
| **向量数据库** | Chroma | 向量检索 |
| **全文检索** | ElasticSearch | 关键词匹配 |
| **Web框架** | FastAPI | REST API + WebSocket |
| **LLM集成** | OpenAI API | 答案生成、意图识别 |
| **容器化** | Docker Compose | 服务编排 |

### 3.2 LangGraph工作流设计

**工作流节点**：
1. 输入验证 → 2. 敏感词检测 → 3. 意图识别 → 4. 实体提取 
→ 5. 知识路由 → 6. 混合检索 → 7. 上下文增强 
→ 8. 答案生成 → 9. 质量检查 → 10. 输出过滤 
→ 11. 保存记录

**核心优势**：
- ✅ 状态机模式，流程清晰可控
- ✅ 条件分支，支持复杂逻辑
- ✅ 异步执行，性能优秀
- ✅ 易于调试和优化

### 3.3 混合检索策略

```
用户查询
    ↓
┌───┴────┬─────────┬──────────┐
│        │         │          │
向量检索  关键词检索  专业词库
(Chroma) (ElasticSearch) (同义词扩展)
  Top 20    Top 20      查询增强
    │        │          │
    └────────┼──────────┘
             ↓
        RRF融合算法
             ↓
        重排序+阈值过滤
             ↓
        Top 3-5 结果
```

**关键技术**：
- **向量检索**：语义相似度匹配（Cosine距离）
- **关键词检索**：精确词汇匹配（BM25算法）
- **RRF算法**：`score(d) = Σ 1 / (k + rank_i(d))`
- **专业词库**：同义词扩展、实体识别

### 3.4 数据库设计要点

#### MongoDB（6个核心集合）
1. `conversations`：对话会话（索引：session_id, user_id）
2. `knowledge_docs`：知识文档（索引：doc_id, kb_id）
3. `faqs`：FAQ问答（索引：faq_id, category）
4. `intents`：意图配置（索引：intent_id）
5. `custom_dictionaries`：专业词库（索引：dict_id）
6. `sensitive_words`：敏感词库（索引：sen_dict_id）

#### Chroma（2个向量集合）
1. `faq_collection`：FAQ向量（1536维）
2. `doc_collection`：文档向量（1536维）

#### ElasticSearch（2个索引）
1. `faq_index`：FAQ全文索引（IK分词）
2. `doc_index`：文档全文索引（IK分词）

class ConversationState(TypedDict):
    user_query: str
    session_id: str
    intent: str
    retrieved_docs: list
    final_answer: str
    confidence: float

def build_conversation_graph():
    graph = StateGraph(ConversationState)
    
    # 添加节点
    graph.add_node("validate_input", validate_input)
    graph.add_node("recognize_intent", recognize_intent)
    graph.add_node("hybrid_search", hybrid_search)
    graph.add_node("generate_answer", generate_answer)
    
    # 添加边
    graph.add_edge("validate_input", "recognize_intent")
    graph.add_edge("recognize_intent", "hybrid_search")
    graph.add_edge("hybrid_search", "generate_answer")

    graph.set_entry_point("validate_input")

### 5.3 混合检索实现

```python
async def hybrid_search(query: str, top_k: int = 5) -> List[Dict]:
    """混合检索"""
    # 1. 并行执行向量和关键词检索
    vector_results, keyword_results = await asyncio.gather(
        vector_retrieval.search(query, top_k=20),
        keyword_retrieval.search(query, top_k=20)
    )
    
    # 2. RRF融合
    merged = rrf_fusion(vector_results, keyword_results, k=60)
    
    # 3. 返回Top K
    return merged[:top_k]

def rrf_fusion(vector_results, keyword_results, k=60):
    """RRF算法"""
    scores = {}
    for rank, item in enumerate(vector_results):
        scores[item["id"]] = scores.get(item["id"], 0) + 1/(k + rank + 1)
    for rank, item in enumerate(keyword_results):
        scores[item["id"]] = scores.get(item["id"], 0) + 1/(k + rank + 1)
    
    return sorted(scores.items(), key=lambda x: x[1], reverse=True)
```
