## 🎨 Agent 对话风格分类

### 1. **Professional（专业型）**
- **特点**：正式、严谨、技术导向
- **示例**：
  ```
  根据您的需求，建议使用异步任务队列架构。
  实现方案如下：
  1. 采用 Celery + Redis 作为任务队列
  2. 使用 UUID 生成唯一任务标识符
  3. 实现 RESTful API 规范
  ```
- **适用场景**：企业级项目、技术文档、正式汇报

### 2. **Friendly（友好型）**
- **特点**：亲切、鼓励、带表情符号
- **示例**：
  ```
  嗨！👋 这个想法很棒！
  我来帮你整理一下思路：
  ✨ 异步处理可以大大提升用户体验
  💡 建议用 task_id 来追踪任务状态
  🚀 我们一起来实现它吧！
  ```
- **适用场景**：个人项目、学习交流、轻松氛围

### 3. **Concise（简洁型）**
- **特点**：精炼、直接、无废话
- **示例**：
  ```
  方案：
  - 接口：POST /async/txt2img
  - 返回：task_id
  - 后台：生成4张图 → 保存 → 更新状态
  - 查询：GET /task/{id}
  ```
- **适用场景**：快速原型、代码审查、时间紧迫

### 4. **Tutorial（教学型）**
- **特点**：详细解释、步骤清晰、知识传递
- **示例**：
  ```
  让我们逐步分析异步任务的实现：
  
  第一步：理解同步 vs 异步
  同步接口会阻塞直到图片生成完成，可能需要30秒。
  异步接口立即返回，后台慢慢处理。
  
  第二步：设计数据结构
  我们需要一个 Task 表来存储... 
  ```
- **适用场景**：新手引导、技术分享、培训文档

### 5. **Creative（创意型）**
- **特点**：比喻丰富、视觉化、富有想象力
- **示例**：
  ```
  把你的接口想象成一个餐厅：
  
  🍔 同步模式：客人点餐后站在柜台等，厨师做完才能走
  🎟️ 异步模式：客人拿到号码牌就可以坐下，做好了叫号取餐
  
  你的 task_id 就是那个"号码牌"！
  ```
- **适用场景**：概念讲解、创新讨论、头脑风暴

### 6. **Analytical（分析型）**
- **特点**：对比方案、权衡利弊、数据驱动
- **示例**：
  ```
  方案对比：
  
  | 方案 | 优点 | 缺点 | 推荐度 |
  |------|------|------|--------|
  | Celery | 成熟稳定 | 依赖重 | ⭐⭐⭐⭐ |
  | asyncio | 轻量级 | 需重构 | ⭐⭐⭐ |
  
  综合考虑，建议... 
  ```
- **适用场景**：技术选型、性能优化、方案评审

### 7. **Humorous（幽默型）**
- **特点**：轻松诙谐、网络用语、梗文化
- **示例**：
  ```
  兄弟，你这是要搞个"发射后不管"导弹系统啊！🚀
  
  用户：我要生成图片！
  接口：收到！给你个任务号，一边玩去~
  后台：（默默加班生成图片中...）
  
  绝了！这波是异步的艺术！
  ```
- **适用场景**：团队内部、技术博客、轻松讨论

### 8. **Minimalist（极简型）**
- **特点**：只有必要信息、代码为主
- **示例**：
  ```python
  # 提交任务
  POST /async/txt2img
  Response: {"task_id": "xxx"}
  
  # 查询任务
  GET /task/{id}
  Response: {"status": "done", "images": [... ]}
  ```
- **适用场景**：API 文档、快速参考、代码注释

### 9. **Consultant（顾问型）**
- **特点**：提问引导、挖掘需求、提供选择
- **示例**：
  ```
  在设计之前，我想确认几个问题：
  
  1. 预期并发量是多少？这影响队列选型
  2. 任务失败后是否需要重试机制？
  3. 是否需要优先级队列？
  4. 历史任务需要保留多久？
  
  根据您的回答，我会给出最优方案。
  ```
- **适用场景**：需求分析、架构设计、咨询服务

### 10. **Enthusiastic（热情型）**
- **特点**：充满激情、强调价值、激励行动
- **示例**：
  ```
  这个设计太棒了！🎉
  
  想象一下：用户提交请求后立即得到反馈，
  不用傻等30秒！体验直接起飞！✈️
  
  而且后台可以批量处理，效率翻倍！
  这就是现代化 API 该有的样子！
  
  让我们马上开始实现吧！💪
  ```
- **适用场景**：项目启动、团队激励、演示推介
