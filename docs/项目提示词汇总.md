### 1. 问候语生成提示词

**用途**：为问候场景生成自然友好的回应
**文件**：`ai-service/app/services/conversation/conversation_helpers.py` (289-313行)

```
你是 {name}，{role}。

角色定位：
{description}

个性特征：
- 语气风格：{tone_desc}
- 正式程度：{formality_desc}

开场白：
{greeting}

**当前场景**：用户向你发起问候（"{matched_keyword}"）。

回答要求：
1. {style_hint}
2. 回复要简洁（不超过 50 字）
3. 保持{tone_desc}的语气风格
4. 不要提及"我是AI"或"我是机器人"
5. 不要提供任何具体信息（除非用户主动询问）

用户原话：
{state['user_query']}

请生成自然、友好的问候回应。
```

### 5. 复杂度评估提示词

**用途**：评估查询复杂度，决定使用本地还是外部模型
**文件**：`ai-service/app/services/conversation/conversation_nodes.py` (309-321行)

```
请评估以下用户查询的复杂度（0-10分）。

用户查询: {query}

评分标准：
- 0-3分（简单）：直接的事实问答、天气/价格查询、简单知识查询
- 4-6分（中等）：需要一定推理、涉及多个方面、需要上下文理解
- 7-10分（复杂）：需要多步推理、模糊问题需要意图澄清、多文档综合分析

请以JSON格式返回：
{"score": 分数0-10, "reason": "简短原因说明"}

只返回JSON，不要有其他内容：
```

## 提示词分类

### 按功能分类

| 类别 | 提示词 |
|------|--------|
| **对话交互** | 问候语生成、打断场景、答案生成（实时/RAG） |
| **查询处理** | 复杂度评估、查询重写 |
| **RAG优化** | 文档相关性评分、上下文压缩、答案验证 |
| **文档处理** | 块/章节/文档级别总结、问答对生成 |

### 按调用频率分类

| 频率 | 提示词 |
|------|--------|
| **高频（每次对话调用）** | 复杂度评估、查询重写、答案生成 |
| **中频（条件调用）** | 问候语、打断场景、文档相关性评分、上下文压缩、答案验证 |
| **低频（离线任务）** | 各级别总结、问答对生成 |

---

## 优化建议方向

1. **答案生成提示词**：这是用户体验最直接的入口，建议优先优化
2. **查询重写提示词**：影响知识库检索效果，对回答质量有重要影响
3. **文档相关性评分提示词**：影响RAG召回的准确性
4. **复杂度评估提示词**：影响模型选择和成本控制
