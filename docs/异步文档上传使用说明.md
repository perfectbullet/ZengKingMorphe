# 异步文档上传功能使用说明

## 概述

文档上传接口已优化为支持**异步任务模式**，允许用户立即获得任务 ID 并在后台处理文档，避免长时间等待和请求超时。

## 功能特性

1. ✅ **异步提交** - 上传文档后立即返回任务 ID
2. ✅ **任务跟踪** - 查询任务状态、进度、结果
3. ✅ **进度更新** - 实时显示切片处理进度（0-100%）
4. ✅ **任务取消** - 支持取消待处理或进行中的任务
5. ✅ **后台队列** - 使用 asyncio.Queue 管理任务队列
6. ✅ **自动启动** - FastAPI 启动时自动启动任务处理器

## API 接口

### 1. 上传文档（异步模式）

**Endpoint**: `POST /api/knowledge_base/documents/upload`

**参数**:
- `files` (File[]) - 上传的文件列表（最多 50 个）
- `kb_id` (string) - 知识库 ID
- `category` (string, optional) - 文档分类
- `async_mode` (boolean) - **是否使用异步模式**（默认 false）

**请求示例**:
```bash
curl -X POST "http://localhost:8100/api/knowledge_base/documents/upload" \
  -H "X-API-Key: your-api-key" \
  -F "files=@document1.pdf" \
  -F "files=@document2.docx" \
  -F "kb_id=kb_abc123" \
  -F "category=product_manual" \
  -F "async_mode=true"
```

**成功响应** (async_mode=true):
```json
{
  "status": "success",
  "message": "Submitted 2 tasks for processing",
  "tasks": [
    "document_task_202512172015_a7b3c8d1",
    "document_task_202512172015_f4e9d2a6"
  ]
}
```

**成功响应** (async_mode=false, 同步模式):
```json
{
  "status": "success",
  "results": [
    {
      "filename": "document1.pdf",
      "doc_id": "doc_abc123",
      "chunks_count": 45,
      "status": "success"
    }
  ],
  "summary": {
    "total": 1,
    "success": 1,
    "failed": 0
  }
}
```

### 2. 查询任务状态

**Endpoint**: `GET /api/knowledge_base/documents/tasks/{task_id}`

**参数**:
- `task_id` (path) - 任务 ID

**请求示例**:
```bash
curl -X GET "http://localhost:8100/api/knowledge_base/documents/tasks/document_task_202512172015_a7b3c8d1" \
  -H "X-API-Key: your-api-key"
```

**成功响应**:
```json
{
  "status": "success",
  "task": {
    "task_id": "document_task_202512172015_a7b3c8d1",
    "kb_id": "kb_abc123",
    "filename": "document1.pdf",
    "file_path": "/tmp/uploads/document1.pdf",
    "category": "product_manual",
    "status": "running",
    "doc_id": "doc_xyz789",
    "total_chunks": 45,
    "processed_chunks": 23,
    "progress": 51.11,
    "error_message": null,
    "created_at": "2025-12-17T20:15:30Z",
    "started_at": "2025-12-17T20:15:31Z",
    "completed_at": null,
    "metadata": {}
  }
}
```

**任务状态说明**:
- `pending` - 等待处理
- `running` - 正在处理
- `completed` - 处理完成
- `failed` - 处理失败
- `cancelled` - 已取消

**进度字段**:
- `total_chunks` - 总切片数
- `processed_chunks` - 已处理切片数
- `progress` - 处理进度（0-100）

### 3. 取消任务

**Endpoint**: `DELETE /api/knowledge_base/documents/tasks/{task_id}`

**参数**:
- `task_id` (path) - 任务 ID

**请求示例**:
```bash
curl -X DELETE "http://localhost:8100/api/knowledge_base/documents/tasks/document_task_202512172015_a7b3c8d1" \
  -H "X-API-Key: your-api-key"
```

**成功响应**:
```json
{
  "status": "success",
  "message": "Task document_task_202512172015_a7b3c8d1 cancelled"
}
```

**失败响应**:
```json
{
  "detail": "Task cannot be cancelled (not found or already completed)"
}
```

**取消规则**:
- ✅ 可取消状态：`pending`, `running`
- ❌ 不可取消状态：`completed`, `failed`, `cancelled`

---

## 任务 ID 格式

任务 ID 格式：`document_task_{YYYYMMDDHHmm}_{8位随机字符}`

示例：`document_task_202512172015_a7b3c8d1`

- `202512172015` - 时间戳（2025年12月17日 20:15）
- `a7b3c8d1` - 8 位随机字符（小写字母+数字）

## 使用场景

### 场景 1: 批量上传大文件

**问题**: 上传 50 个 PDF 文件，同步处理超时

**解决方案**: 使用异步模式
```python
import requests

files = [('files', open(f'doc{i}.pdf', 'rb')) for i in range(50)]
data = {'kb_id': 'kb_123', 'async_mode': 'true'}

response = requests.post(
    'http://localhost:8100/api/knowledge_base/documents/upload',
    headers={'X-API-Key': 'your-key'},
    files=files,
    data=data
)

task_ids = response.json()['tasks']
print(f"Submitted {len(task_ids)} tasks")

# 轮询任务状态
for task_id in task_ids:
    status = requests.get(
        f'http://localhost:8100/api/knowledge_base/documents/tasks/{task_id}',
        headers={'X-API-Key': 'your-key'}
    ).json()['task']
    
    print(f"{task_id}: {status['status']} ({status['progress']}%)")
```

### 场景 2: 实时进度监控

**需求**: 前端显示文档处理进度条

**实现**:
```javascript
async function uploadAndMonitor(files, kbId) {
  // 1. 提交任务
  const formData = new FormData();
  files.forEach(file => formData.append('files', file));
  formData.append('kb_id', kbId);
  formData.append('async_mode', 'true');
  
  const uploadRes = await fetch('/api/knowledge_base/documents/upload', {
    method: 'POST',
    headers: {'X-API-Key': 'your-key'},
    body: formData
  });
  
  const {tasks} = await uploadRes.json();
  
  // 2. 轮询进度
  for (const taskId of tasks) {
    const interval = setInterval(async () => {
      const statusRes = await fetch(`/api/knowledge_base/documents/tasks/${taskId}`, {
        headers: {'X-API-Key': 'your-key'}
      });
      
      const {task} = await statusRes.json();
      
      // 更新进度条
      updateProgressBar(taskId, task.progress);
      
      // 完成或失败时停止轮询
      if (['completed', 'failed', 'cancelled'].includes(task.status)) {
        clearInterval(interval);
        handleCompletion(task);
      }
    }, 2000); // 每 2 秒查询一次
  }
}
```

### 场景 3: 用户取消上传

**需求**: 用户点击"取消"按钮停止处理

**实现**:
```python
import requests

# 上传文档
response = requests.post(
    'http://localhost:8100/api/knowledge_base/documents/upload',
    headers={'X-API-Key': 'your-key'},
    files={'files': open('large_file.pdf', 'rb')},
    data={'kb_id': 'kb_123', 'async_mode': 'true'}
)

task_id = response.json()['tasks'][0]

# 用户点击取消
cancel_response = requests.delete(
    f'http://localhost:8100/api/knowledge_base/documents/tasks/{task_id}',
    headers={'X-API-Key': 'your-key'}
)

if cancel_response.status_code == 200:
    print("Task cancelled successfully")
```

## 系统架构

### 组件关系

```
FastAPI (main.py)
    ↓
lifespan context
    ↓
task_processor.start()  ← 启动后台任务处理器
    ↓
DocumentTaskProcessor
    ├── asyncio.Queue (task_queue)
    ├── worker_task (_process_tasks)
    └── active_tasks (cancellation flags)
        ↓
    DocumentProcessor.process_document()
        ├── _extract_text()
        ├── _chunk_text()
        └── _process_chunks() ← 进度更新
            ├── ChromaDB.add_documents()
            └── ElasticSearch.index_document()
```

### 任务生命周期

1. **提交阶段**:
   - 用户调用 `POST /documents/upload?async_mode=true`
   - 生成任务 ID
   - 保存文件到 `/tmp/uploads`
   - 创建 `DocumentTaskModel` 记录（status=pending）
   - 添加到 `task_queue`
   - 返回任务 ID

2. **处理阶段**:
   - 后台 worker 从队列获取任务
   - 更新状态为 `running`
   - 调用 `DocumentProcessor.process_document()`
   - 每处理一个切片更新 `processed_chunks` 和 `progress`
   - 完成后更新状态为 `completed`

3. **查询阶段**:
   - 用户调用 `GET /documents/tasks/{task_id}`
   - 从 MongoDB 读取任务记录
   - 返回状态、进度、结果

4. **取消阶段**:
   - 用户调用 `DELETE /documents/tasks/{task_id}`
   - 如果 `pending`：直接更新状态为 `cancelled`
   - 如果 `running`：设置取消标志，worker 检测后停止

## 注意事项

1. **同步/异步模式**: 通过 `async_mode` 参数控制，默认为 `false`（同步模式）
2. **轮询频率**: 建议每 2-5 秒查询一次任务状态，避免过于频繁
3. **任务清理**: 目前任务记录永久保存在 MongoDB，建议定期清理已完成任务
4. **并发限制**: 使用单个 worker 处理队列，可扩展为多 worker 提升吞吐
5. **文件存储**: 上传文件临时存储在 `/tmp/uploads`，处理后不会自动删除
