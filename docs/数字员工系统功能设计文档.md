# 数字员工系统功能设计文档

## 文档信息
- **版本**：v1.0
- **创建日期**：2025-12-11
- **目标**：基于需求文档和架构设计，详细设计系统功能模块

---

## 1. 系统概述

### 1.1 项目定位
企业级AI对话助手平台，支持多知识库、意图识别、对话管理的智能客服/助手系统。

### 1.2 团队配置
- 1名前端工程师（Vue.js）
- 1名AI研发工程师（Python AI引擎）
- 2名其他工程师

### 1.3 核心目标
提升Agent回答的**准确性**，通过优化知识库召回、意图理解和答案生成质量。

---

## 2. 功能模块设计

## 2.1 对话管理系统

### 2.1.1 知识库配置
**功能描述**：为数字员工配置多个知识库，支持不同业务场景。

**功能点**：
- 知识库列表管理（创建、编辑、删除、启用/禁用）
- 支持多知识库并行使用
- 知识库优先级设置
- 知识库分类标签管理

**数据结构**：
```json
{
  "kb_id": "kb_001",
  "name": "产品知识库",
  "description": "包含产品功能、使用说明等",
  "type": "rag|faq",
  "priority": 1,
  "status": "active|inactive",
  "tags": ["产品", "技术支持"],
  "created_at": "2025-12-11T00:00:00Z",
  "updated_at": "2025-12-11T00:00:00Z"
}
```

**API接口**：
- `POST /api/knowledge-base` - 创建知识库
- `GET /api/knowledge-base` - 获取知识库列表
- `PUT /api/knowledge-base/{id}` - 更新知识库
- `DELETE /api/knowledge-base/{id}` - 删除知识库

```json
{
  "greeting_config": {
    "first_visit": "您好，我是{{employee_name}}，很高兴为您服务！",
    "return_visit": "欢迎回来！我是{{employee_name}}，有什么可以帮您？",

      "employee_name": "小智",
      "company_name": "XX公司"

      "question": "如何重置密码？",
```

### 2.1.3 对话规则配置
**功能描述**：设置对话行为规则、异常处理和安全规则。

**功能点**：

**1. 对话行为规则**
- 最大对话轮次限制
- 超时自动结束会话
- 重复问题检测与提示
- 无效输入处理策略

**2. 异常处理规则**
- 无法理解时的回复话术
- 知识库无匹配时的处理
- 置信度低于阈值时转人工
- 错误重试机制

**3. 安全规则**
- 敏感信息脱敏（手机号、身份证）
- 恶意输入拦截
- 频率限制（防刷）
- 内容合规检查

**数据结构**：
```json
{
  "conversation_rules": {
    "max_turns": 20,
    "session_timeout": 1800,
    "repeat_threshold": 3,
    "confidence_threshold": 0.75
  },
  "exception_handling": {
    "no_match_response": "抱歉，我没有找到相关信息，您可以换个说法试试。",
    "low_confidence_action": "transfer_human",
    "error_retry_count": 3
  },
  "security_rules": {
    "enable_sensitive_filter": true,
    "enable_malicious_check": true,
    "rate_limit": {
      "max_requests_per_minute": 10,
      "max_requests_per_hour": 100
    }
  }
}
```

**API接口**：
- `PUT /api/conversation/rules` - 更新对话规则
- `GET /api/conversation/rules` - 获取对话规则

## 2.3 知识库系统

### 2.3.1 RAG文档库管理

#### 2.3.1.1 文档上传
**功能描述**：上传文档并自动处理为知识片段。

**支持的文件格式**：
- PDF、Word、TXT、Markdown
- HTML、CSV、Excel

**处理流程**：
1. 文件上传验证
2. 文档解析提取文本
3. 文本分块（Chunking）
4. 向量化（Embedding）
5. 存储到向量数据库和MongoDB

**功能点**：
- 批量上传
- 上传进度显示
- 文档预处理（OCR、格式转换）
- 元数据提取（标题、作者、日期）

**API接口**：
- `POST /api/documents/upload` - 上传文档
- `GET /api/documents/upload/{task_id}` - 查询上传进度

---

#### 2.3.1.2 知识片段管理
**功能描述**：手动管理和编辑知识片段。

**功能点**：
- 查看文档的所有知识片段
- 编辑片段内容
- 删除无效片段
- 手动添加知识片段
- 片段合并与拆分

**数据结构**：
```json
{
  "chunk_id": "chunk_001",
  "document_id": "doc_123",
  "content": "密码重置步骤：1. 点击忘记密码...",

    "page_number": 5

  "vector_id": "vec_001",

}
```

**API接口**：
- `GET /api/documents/{id}/chunks` - 获取文档片段
- `POST /api/chunks` - 创建知识片段
- `PUT /api/chunks/{id}` - 更新知识片段
- `DELETE /api/chunks/{id}` - 删除知识片段

#### 2.3.2.2 FAQ检索策略
**功能描述**：混合检索策略（向量 + 关键词）。

**检索流程**：
1. 用户问题向量化
2. Chroma向量检索（Top 20）
3. ElasticSearch关键词检索（Top 20）
4. RRF算法融合排序
5. 相似度阈值过滤
6. 返回Top 3-5结果

**配置参数**：
```json
{
  "faq_retrieval": {
    "vector_weight": 0.7,
    "keyword_weight": 0.3,
    "rrf_k": 60,
    "min_score": 0.75,
    "max_results": 5
  }
}
```

**API接口**：
- `POST /api/faqs/search` - FAQ检索
- `PUT /api/faqs/retrieval-config` - 更新检索配置

---

#### 2.3.2.3 FAQ答案一致性保证
**功能描述**：确保相同问题返回相同答案。

**实现机制**：
- 相似问题聚类
- 标准答案版本管理
- 答案变更审核流程
- 答案质量评分

**API接口**：
- `POST /api/faqs/{id}/versions` - 创建答案新版本
- `GET /api/faqs/{id}/versions` - 获取答案历史版本
- `PUT /api/faqs/{id}/rollback` - 回滚到历史版本

## 5. AI核心算法设计

### 5.1 混合检索策略（RRF算法）

**Reciprocal Rank Fusion算法**：

```python
def rrf_fusion(vector_results, keyword_results, k=60):
    """
    RRF融合算法
    score(d) = Σ 1 / (k + rank_i(d))
    """
    scores = {}
    
    # 向量检索结果打分
    for rank, item in enumerate(vector_results):
        doc_id = item['id']
        scores[doc_id] = scores.get(doc_id, 0) + 1 / (k + rank + 1)
    
    # 关键词检索结果打分
    for rank, item in enumerate(keyword_results):
        doc_id = item['id']
        scores[doc_id] = scores.get(doc_id, 0) + 1 / (k + rank + 1)
    
    # 排序
    sorted_results = sorted(scores.items(), key=lambda x: x[1], reverse=True)
    return sorted_results
```

```python
async def classify_intent(user_query, context=None):
    """
    意图识别流程
    """
    # 1. 加载意图列表
    intents = await get_active_intents()
    
    # 2. 构建Prompt
    prompt = f"""
    用户问题：{user_query}
    
    上下文：{context or '无'}
    
    可选意图：
    {format_intents(intents)}
    
    请返回最匹配的意图ID和置信度（0-1）。
    """
    
    # 3. LLM识别
    response = await llm_client.classify(prompt)
    
    # 4. 解析结果
    intent_id = response['intent_id']
    confidence = response['confidence']
    
    # 5. 置信度阈值判断
    if confidence < 0.75:
        return None, confidence
    
    return intent_id, confidence
```

```python
    """
    根据意图选择检索策略
    """
    routing_rules = await get_routing_rules()
```

### 5.4 答案质量评估

```python
def evaluate_answer_quality(answer, context, user_query):
    """
    评估答案质量
    """
    criteria = {
        "relevance": 0,      # 相关性
        "completeness": 0,   # 完整性
        "accuracy": 0,       # 准确性
        "clarity": 0         # 清晰度
    }
    
    # 使用LLM评估
    evaluation_prompt = f"""
    用户问题：{user_query}
    上下文：{context}
    生成答案：{answer}
    
    请从以下维度评估答案质量（0-1分）：
    1. 相关性：答案是否回答了用户问题
    2. 完整性：答案是否完整，有无遗漏
    3. 准确性：答案是否准确，有无错误
    4. 清晰度：答案是否清晰易懂
    """
    
    evaluation = llm_client.evaluate(evaluation_prompt)
    
    # 计算综合得分
    overall_score = sum(evaluation.values()) / len(evaluation)
    
    return overall_score, evaluation
```
