## 🎨 核心内容速览（更新版）

### 1. 需求总结

```
数字员工系统（核心功能优先）
├── 对话引擎模块（简化）
│   ├── 对话接口（REST + SSE流式响应）✅ 核心
│   ├── 上下文管理（简化版）
│   ├── 流式响应（仅SSE）✅ 核心
│   └── 敏感词拦截（Java接口集成）
│
├── 知识库系统（核心）
│   ├── RAG文档库（上传、解析、向量化）✅ 最高优先级
│   ├── 文档相关性评分（0-1分，阈值0.6）✅ 核心
│   ├── FAQ问答库（Java接口集成）
│   └── 联网检索（Tavily/SerpAPI）✅ 核心
│
├── 意图识别模块（简化）
│   ├── 基于规则的关键词匹配
│   └── 实时信息类vs知识库查询类
│
└── 对话记录分析
    └── 记录查看/搜索/统计
```

### 2. 技术架构（更新版）

**核心技术栈**：
- 🔧 **工作流编排**：LangGraph（状态机）
- 🗄️ **文档数据库**：MongoDB
- 🔍 **向量检索**：Chroma
- 🔎 **全文检索**：ElasticSearch
- 🌐 **Web框架**：FastAPI
- 🤖 **LLM集成**：OpenAI API
- 🌍 **联网检索**：Tavily API ✅ 新增
- 🔗 **Java集成**：FAQ、敏感词接口 ✅ 新增
- 📡 **流式输出**：SSE（Server-Sent Events）✅ 核心
- 🐳 **容器化**：Docker Compose

**核心工作流（更新版）**：
```
用户查询
    ↓
RAG向量检索
    ↓
文档相关性评分 ✅ 新增
    ↓
┌─────────┴──────────┐
│ 分数>=0.6?          │
└──┬──────────┬──────┘
   │          │
  是         否
   │          │
   │      联网检索 ✅ 新增
   │          │
   └────┬─────┘
        ↓
   答案生成（LLM）
        ↓
   SSE流式输出 ✅ 核心
```

## 💡 关键亮点（更新版）

### 1. 基于LangGraph的状态机工作流

```python
# 核心节点流程（简化优化版）
输入验证 → 敏感词检测 → RAG向量检索 
→ 文档相关性评分 ✅ → 联网检索（条件触发）✅
→ 答案生成 → 输出过滤 → SSE流式输出 ✅
```

### 2. 智能检索策略（核心优势）

```
用户查询
    ↓
RAG向量检索(Chroma)
    ↓
文档相关性评分（LLM评分，0-1分）✅ 新增
    ↓
┌─────────────┴──────────────┐
│ 相关性 >= 0.6?              │
└──┬───────────────┬──────────┘
   │               │
  高分            低分/无结果
   │               │
使用文档      联网检索(Tavily) ✅ 新增
   │               │
   └───────┬───────┘
           ↓
      答案生成（LLM）
           ↓
      SSE流式输出 ✅
```

- **Webhook通知**：Java端数据变更时主动通知AI端更新索引
