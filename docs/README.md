## 🎨 核心内容速览

### 1. 需求总结

```
数字员工系统（5大核心模块）
├── 对话引擎模块
│   ├── 对话接口（REST + WebSocket）
│   ├── 多知识库路由
│   ├── 多轮对话管理
│   ├── 流式响应
│   └── 敏感词拦截
│
├── 知识库系统
│   ├── RAG文档库
│   ├── FAQ问答库
│   ├── 混合检索（向量+关键词+RRF）
│   └── 知识库质量管理
│
├── 意图识别模块
│   ├── 意图配置管理
│   ├── 基于LLM的识别
│   ├── 实体提取（NER）
│   └── 意图路由
│
├── 词库管理
│   ├── 专业词库
│   ├── 敏感词库
│   ├── 停用词库
│   └── 同义词库
│
└── 对话记录分析
    ├── 记录查看/搜索
    ├── 数据统计分析
    └── 对话回放
```

### 2. 技术架构

**核心技术栈**：
- 🔧 **工作流编排**：LangGraph（状态机）
- 🗄️ **文档数据库**：MongoDB
- 🔍 **向量检索**：Chroma
- 🔎 **全文检索**：ElasticSearch
- 🌐 **Web框架**：FastAPI
- 🤖 **LLM集成**：OpenAI API
- 🐳 **容器化**：Docker Compose

**系统架构**：
```
前端层（Vue.js）
    ↓
API网关层（FastAPI）
    ↓
业务服务层（对话管理、知识库管理、任务编排）
    ↓
AI引擎层（LangGraph + 对话引擎 + 知识检索 + 意图识别）
    ↓
数据存储层（MongoDB + Chroma + ElasticSearch + Redis）
```

### 3. 开发路线图（7周）

| 阶段 | 时间 | 目标 |
|------|------|------|
| Phase 1 | 2周 | 基础服务搭建（FastAPI + LangGraph + 数据库） |
| Phase 2 | 2周 | 知识库与检索（FAQ + RAG + 混合检索） |
| Phase 3 | 1.5周 | 意图识别与质量保障 |
| Phase 4 | 1.5周 | 系统集成与优化 |

### 1. 基于LangGraph的状态机工作流

```python
# 11个节点的完整对话流程
```

### 2. 混合检索策略（提升准确性）

```
用户查询
    ↓

    ↓
RRF融合算法
    ↓
重排序 + 阈值过滤
    ↓
Top 3-5 高质量结果
```
