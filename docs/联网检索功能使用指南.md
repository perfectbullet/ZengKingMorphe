# 联网检索功能使用指南

## 功能概述

联网检索功能已集成到对话工作流中，使用 **Tavily API** 实现实时网络信息检索。该功能会在以下两种情况下自动触发：

1. **实时查询检测**：当用户问题包含实时性关键词（天气、新闻、股价等）时
2. **知识库相关度低**：当知识库检索结果相关度评分 < 0.6 时

## 配置说明

### 环境变量配置

在 `.env` 文件中配置以下参数：

```bash
# Tavily API 密钥（必需）
TAVILY_API_KEY=tvly-your-api-key-here

# 全局开关（默认：true）
WEB_SEARCH_ENABLED=true

# 超时时间（秒，默认：5）
WEB_SEARCH_TIMEOUT=5

# 最大返回结果数（默认：5，范围：1-10）
WEB_SEARCH_MAX_RESULTS=5

# 是否仅用于实时查询（默认：false）
WEB_SEARCH_ONLY_FOR_REALTIME=false
```

### 数字员工配置

每个数字员工可以单独配置是否启用联网检索：

```json
{
  "employee_id": "emp_001",
  "name": "AI助手",
  "capabilities": {
    "web_search_enabled": true,
    "kb_ids": ["kb_001", "kb_002"]
  }
}
```

## 工作流程

### 1. 触发条件

#### 实时查询检测
系统会检查用户问题中是否包含以下关键词：

- **时间类**：今天、明天、昨天、最近、现在、本周、本月、当前
- **天气类**：天气、气温、降雨、降水、温度
- **新闻类**：新闻、热点、最新、资讯、动态、头条
- **市场类**：股价、汇率、行情、股市

#### RAG 相关度低
如果知识库检索结果的相关度评分 < 0.6（可通过 `RELEVANCE_THRESHOLD` 配置），系统会自动进行联网检索作为补充。

### 2. 搜索流程

```python
# 1. 检查配置
if not settings.web_search_enabled:
    return  # 全局禁用

if not settings.tavily_api_key:
    return  # API key 未配置

if not employee_config.capabilities.web_search_enabled:
    return  # 员工级别禁用

# 2. 调用 Tavily API
search_results = await self.web_search_tool.ainvoke({"query": user_query})

# 3. 格式化结果
formatted_results = [
    {
        "rank": i,
        "title": result["title"],
        "url": result["url"],
        "content": result["content"][:500],  # 截取前 500 字符
        "score": result["score"]
    }
    for i, result in enumerate(results[:5], 1)
]

# 4. 更新状态
state["web_search_results"] = formatted_results
state["web_search_used"] = True
```

### 3. 结果整合

搜索结果会被整合到 LLM 的上下文中：

```python
# 知识库参考
[知识库参考1] 内容...
[知识库参考2] 内容...

# 网络资料（如果有联网检索结果）
[网络资料1] 标题
内容摘要...
来源: URL

[网络资料2] 标题
内容摘要...
来源: URL
```

### 4. 置信度计算

系统会根据信息来源自动调整回答的置信度：

- **FAQ 匹配**：0.95（最高）
- **联网检索**：≥ 0.75（基于搜索结果平均分数）
- **知识库检索**：≥ 0.6（基于相关度评分）
- **基础**：0.5

## 错误处理

联网检索失败不会导致整个对话流程失败：

```python
try:
    search_results = await self.web_search_tool.ainvoke({"query": query})
except Exception as e:
    logger.error("Web search failed", error=str(e))
    # 继续执行，使用空结果
    state["web_search_results"] = []
    state["web_search_used"] = False
```

## 性能优化建议

1. **超时控制**：建议设置 `WEB_SEARCH_TIMEOUT=5` 秒，避免等待时间过长
2. **结果限制**：`WEB_SEARCH_MAX_RESULTS=5` 可在质量和性能间取得平衡
3. **内容截断**：搜索结果内容自动截断到 500 字符，避免 token 消耗过大
4. **缓存策略**：考虑为热门实时查询添加短期缓存（如天气查询缓存 1 小时）

## 成本控制

Tavily API 按请求计费，建议：

1. 仅对必要场景启用（通过 `WEB_SEARCH_ONLY_FOR_REALTIME=true` 限制）
2. 设置合理的 `RELEVANCE_THRESHOLD`（如 0.6），避免过度触发
3. 监控 `conversations.web_search_used` 统计实际使用率
4. 考虑为高频员工设置 `web_search_enabled: false`

## 常见问题

### Q: 如何禁用某个员工的联网检索？

A: 在员工配置中设置：
```json
{
  "capabilities": {
    "web_search_enabled": false
  }
}
```

### Q: 如何查看联网检索是否被触发？

A: 检查对话响应中的字段：
- `is_realtime_query`: 是否检测为实时查询
- `web_search_used`: 是否使用了联网检索
- `web_search_results`: 搜索结果详情

### Q: 联网检索失败会影响回答吗？

A: 不会。失败时系统会记录错误日志并继续使用知识库结果，确保服务可用性。

### Q: 如何测试实时查询检测？

A: 使用包含关键词的问题，如：
- "今天的天气怎么样？"（天气类）
- "最新的新闻有什么？"（新闻类）
- "当前股市行情如何？"（市场类）
