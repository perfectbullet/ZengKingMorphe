# 01 珐琅工艺 KG 抽取 Profile

## 1. 适用范围

本 profile 仅适用于《01珐琅工艺》这本工业实训 / 首饰工艺教材。

本 profile 必须和工业实训教材统一 schema 配合使用，不得新增 schema 之外的实体类型和关系类型。

抽取目标优先级：

1. 问答准确；
2. 工艺流程结构化；
3. 图文 evidence 检索；
4. 前端图片展示溯源；
5. 后续跨书工业实训知识图谱融合。

本 profile 只约束《01珐琅工艺》的抽取口径，不应破坏其他教材的统一 schema。

---

## 2. 统一 schema 约束

本书只允许使用统一 schema 中的实体类型。

允许实体类型：

- CONCEPT：概念、术语、定义对象、分类对象；
- METHOD：命名工艺、技法、操作方法；
- PROCESS：具体工艺过程、连续操作序列；
- MATERIAL：材料、原料、介质、化学材料；
- TOOL：手工工具、辅助器具、量具、夹具；
- EQUIPMENT：设备、机器、炉、机床；
- PROPERTY：性能、性质、技术要求、参数类别；
- DEFECT：缺陷、问题、失效现象；
- PRODUCT：产品、作品、工艺样件、首饰品类；
- SAFETY_REQUIREMENT：安全要求、注意事项、防护要求。

禁止使用以下实体类型：

- FIGURE
- PERSON
- AUTHOR
- ORGANIZATION
- LOCATION
- DATE
- PAGE
- STEP
- UNKNOWN

注意：

图号、图片、图注不作为实体类型。图号和图注只作为 evidence 或 metadata 使用。

### 反例 5：过泛实体

错误：

- 工具 -> TOOL
- 材料 -> MATERIAL
- 方法 -> METHOD
- 作品 -> PRODUCT

正确：

- 釉料铲 -> TOOL
- 珐琅釉料 -> MATERIAL
- 干筛法 -> METHOD
- 古董胸针 -> PRODUCT

## 10. 输出质量要求

1. 实体名必须短、准、稳定。
2. 不输出纯图号实体。
3. 不输出 FIGURE 实体。
4. 不输出人名、作者、艺术家姓名。
5. 不输出图片路径、URL、hash 文件名。
6. 不输出单独温度、比例、尺寸、页码。
7. 命名工艺优先 METHOD。
8. 具体连续过程优先 PROCESS。
9. 工艺示例作品可以抽 PRODUCT。
10. 图号、图注、图片路径、page_idx、bbox 进入 evidence / metadata。
11. 只抽取输入文本明确出现的教材知识。
12. 不补充文档外知识。
13. 不把 source_missing 目录项用其他章节强行补全。
