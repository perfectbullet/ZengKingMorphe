# Industrial Training KG Schema v1

## 1. Schema Version

schema_version: industrial_training_kg_schema.v1

本 schema 适用于工业实训教材知识图谱，包括但不限于：

- 珐琅工艺
- 珠宝手绘效果图表现
- 首饰设计与创意方法
- 玉石雕刻工艺
- 首饰雕蜡工艺
- 首饰设计表现
- 首饰金属工艺
- 宝石镶嵌工艺
- 首饰效果图表现
- 金工实习

本 schema 是所有教材 profile 必须遵守的统一契约。教材 profile 只能补充本书术语、正反例和局部禁抽规则，不得新增实体类型和关系类型。

---

## 2. Extraction Goals

抽取目标优先级：

1. 问答准确；
2. 工艺流程结构化；
3. 工艺、材料、工具、设备、缺陷、产品之间的知识关系清晰；
4. 支持 source evidence 溯源；
5. 支持图文 evidence 检索；
6. 支持多本教材在同一 working_dir 中融合；
7. 避免图号、图片路径、页码、编号、人名等噪声污染 KG。

---

## 3. Allowed Entity Types

只允许以下实体类型：

### CONCEPT

概念、术语、定义对象、分类对象。适用于抽象术语、分类对象、学科概念、工艺总称、设计原则和理论概念。

示例：珐琅工艺、高温珐琅工艺、宝石镶嵌、首饰设计、透视关系、色彩明度、金属工艺、工艺美术。

### METHOD

命名工艺、技法、操作方法。以“法”“技法”“工艺”“方法”命名且可以被教学、选择、比较和应用的方法，优先标为 METHOD，不要轻易标为 PROCESS。

示例：平铺珐琅工艺、掐丝珐琅工艺、干筛法、勾花法、贴箔、爪镶、包镶、起版、锉修、雕蜡、阴刻、浮雕。

### PROCESS

具体工艺过程、连续操作序列、生产流程，包括多个步骤组成的过程、具体执行过程、工序链以及可拆解前后步骤的操作序列。

示例：釉料研磨和清洗过程、灰度绘绘制过程、金属底板预处理、烧制过程、蜡模制作流程、宝石镶嵌流程、抛光过程、焊接过程。

### MATERIAL

材料、原料、介质、化学材料、半成品材料。

示例：珐琅釉料、透明釉料、红铜、银、金、18K金、蜡、石膏、宝石、玉石、焊药、酸液、蒸馏水、松节油、金属丝。

### TOOL

手工工具、辅助器具、量具、夹具、绘图工具。

示例：研钵、油画刀、镊子、钢钩、锉刀、锯弓、蜡刀、游标卡尺、圆规、毛笔、铅笔、夹具。

### EQUIPMENT

设备、机器、炉、机床、加工装置。

示例：珐琅炉、压片机、超声波清洗机、抛光机、吊机、车床、铣床、钻床、台钻、铸造机、真空机。

### PROPERTY

性能、性质、技术要求、参数类别、质量指标。

示例：熔化温度、烧成温度、清洁度、粗细度、透明度、硬度、延展性、韧性、结合性、附着性、表面粗糙度、尺寸精度、比例关系、明度、色相、透视准确性。

单独数值不要作为实体，数值应写入 description 或 evidence。

### DEFECT

缺陷、问题、失效现象、质量问题。

示例：砂眼、开裂、气泡、崩脱、露底、漏色、变形、划痕、毛刺、焊接缺陷、松动、错位、比例失调、透视错误。

### PRODUCT

产品、作品、零件、工件、工艺样件、首饰品类。

示例：古董胸针、珐琅戒指、珐琅装饰画、蜡模、戒指、吊坠、胸针、宝石戒面、金属工件、玉雕作品、首饰效果图、现代艺术首饰。

### SAFETY_REQUIREMENT

安全要求、注意事项、防护要求、操作禁忌。

示例：防火手套、防护面罩、酸液配置注意事项、高温操作注意事项、通风要求、防尘要求、防割伤要求、用电安全、设备安全操作规程。

## 4. Forbidden Entity Types

禁止输出以下实体类型：

- FIGURE
- PERSON
- AUTHOR
- ORGANIZATION
- LOCATION
- DATE
- PAGE
- STEP
- NUMBER
- UNKNOWN

如果无法判断实体类型，不要输出该实体，而不是输出 UNKNOWN。

---

## 5. Allowed Relation Types

只允许以下关系类型：

### 属于

用于分类、归属、上下位关系。例如：平铺珐琅工艺 - 属于 -> 珐琅工艺；爪镶 - 属于 -> 宝石镶嵌工艺。

### 包括

用于整体包含多个子类、组成部分、知识点。例如：珐琅工艺 - 包括 -> 掐丝珐琅工艺；金属底板预处理 - 包括 -> 清洗。

### 组成

用于结构组成、材料组成、部件组成。例如：珐琅釉料 - 组成 -> 二氧化硅；首饰结构 - 组成 -> 镶口。

### 用于

用于工具、材料、设备的用途。例如：珐琅炉 - 用于 -> 烧制；锉刀 - 用于 -> 锉修。

### 需要

用于工艺、过程、产品对材料、工具、条件、要求的依赖。例如：平铺珐琅工艺 - 需要 -> 珐琅釉料；烧制过程 - 需要 -> 珐琅炉。

### 影响

用于性能、参数、环境对结果的影响。例如：釉料厚度 - 影响 -> 开裂风险；清洁度 - 影响 -> 附着性。

### 导致

用于原因导致缺陷、问题、结果。例如：杂质 - 导致 -> 砂眼；烧制过度 - 导致 -> 颜色变浅。

### 适用于

用于方法、材料、工具适用对象。例如：平铺珐琅工艺 - 适用于 -> 大面积色块；爪镶 - 适用于 -> 宝石镶嵌。

### 步骤

用于工艺到步骤或流程到子步骤。例如：平铺珐琅工艺 - 步骤 -> 金属底板预处理；灰度绘绘制过程 - 步骤 -> 暗部描绘。

### 前置步骤

用于步骤顺序中的前置关系。例如：清洗 - 前置步骤 -> 施釉。

### 后续步骤

用于步骤顺序中的后续关系。例如：施釉 - 后续步骤 -> 烧制。

### 对比

用于两种方法、材料、效果之间的比较。例如：透明釉料 - 对比 -> 不透明釉料。

### 注意事项

用于工艺或操作对应的注意事项、安全要求。例如：酸液配置 - 注意事项 -> 只能向水中加入硫酸。

### 产生

用于工艺、过程产生效果、产品、缺陷。例如：透明釉料叠加 - 产生 -> 渐变效果。

### 改善

用于措施对质量、缺陷、性能的改善。例如：清洗 - 改善 -> 附着性。

### 防止

用于措施防止缺陷或风险。例如：玻璃罩 - 防止 -> 灰尘污染。

## 6. Forbidden Entity Patterns

以下对象禁止作为实体名。

### 6.1 纯图号

禁止：图3-1、图 3-1、图8-13、图 8-50。

处理：figure_no 写入 evidence，caption 写入 evidence.caption，image_path 写入 metadata，不创建 FIGURE 实体。

### 6.2 图片路径、URL、hash 文件名

禁止：images/xxx.jpg、./images/xxx.png、https://cdn-mineru...、5e705c21a05b6fb9ad8f7c8ffa5bf684.jpg。

### 6.3 章节号、目录编号、页码

禁止：第3章、CHAPTER 03、3.1、10.3.2、043、页码。目录信息进入 chunk metadata，不进入实体图谱。

### 6.4 STEP 编号

禁止：STEP 01、STEP02、操作步骤1、步骤1。步骤编号可进入 description/evidence，不作为实体名。

### 6.5 人名、作者、艺术家、感谢名单

禁止作者、艺术家、设计师、感谢名单、译者、编者和出版社人员姓名。当前工业实训 KG 第一版不做人名知识图谱。

### 6.6 单独数值、温度、尺寸、比例

禁止：850摄氏度、900℃、40%、1:1、0.5mm、043。

正确做法：烧制温度标为 PROPERTY，description 写入 850摄氏度；酸液浓度标为 PROPERTY，description 写入 40%；线描稿比例标为 PROPERTY，description 写入 1:1。

### 6.7 过泛实体

避免：工艺、方法、材料、工具、设备、作品、图案、效果、操作、注意事项。优先抽取更具体实体。

## 7. Evidence Rules

evidence 是实体、关系、回答的证据来源，不是核心 KG 实体。

evidence 可以包含：

- chunk_id
- doc_id
- file_path
- catalog_index
- catalog_title
- heading_path
- source_md_path
- figure_no
- caption
- raw_caption
- image_path
- page_idx
- bbox
- source_missing_status

规则：

1. source_id 和 file_path 是最低限度 evidence；
2. 图号只作为 evidence.figure_no；
3. 图注只作为 evidence.caption 或 raw_caption；
4. 图片路径只作为 evidence.image_path 或 chunk.images metadata；
5. source_missing 必须作为查询层 evidence；
6. evidence 不应作为实体节点污染 KG。

---

## 8. Source Missing Rules

如果某目录项被标记为 source_missing：

1. 不得用相邻章节补全；
2. 不得用同名近似章节替代；
3. 回答时必须说明该目录项正文缺失；
4. 可以提示知识库中存在相关但不同章节的内容；
5. 不得将相关章节说成缺失目录项本身。

---

## 9. Output Quality Requirements

1. 实体名短、准、稳定；
2. 只输出允许的实体类型；
3. 只输出允许的关系类型；
4. 不输出 UNKNOWN；
5. 不输出纯图号实体；
6. 不输出 FIGURE；
7. 不输出图片路径实体；
8. 不输出人名实体；
9. 不输出单独数值实体；
10. 不输出目录编号实体；
11. 命名工艺优先 METHOD；
12. 连续过程优先 PROCESS；
13. 工具和设备严格区分；
14. 产品和作品可抽 PRODUCT；
15. 所有知识必须来自输入文本；
16. 不补充文档外知识；
17. 图注信息进入 evidence；
18. source_missing 不得被自动补全。
