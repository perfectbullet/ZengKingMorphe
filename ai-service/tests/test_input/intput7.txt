您提供的题目是求解不等式 \(\frac{x-1}{x+2} \leq 0\) 的解集。

为了解这个不等式，我们需要分析分式的符号变化点和区间。关键点是 \(x = 1\) 和 \(x = -2\)。

通过数轴标出这些点，并检查每个区间的符号：

1. 当 \(x < -2\) 时，分子 \(x-1 < -3 < 0\)，分母 \(x+2 < 0\)，所以 \(\frac{x-1}{x+2} > 0\).
2. 当 \(-2 < x < 1\) 时，分子 \(x-1 < 0\)，分母 \(x+2 > 0\)，所以 \(\frac{x-1}{x+2} < 0\).
3. 当 \(x = -2\) 时，分式无定义。
4. 当 \(x = 1\) 时，分子为零，因此 \(\frac{x-1}{x+2} = 0\).
5. 当 \(x > 1\) 时，分子 \(x-1 > 0\)，分母 \(x+2 > 0\)，所以 \(\frac{x-1}{x+2} > 0\).

综合上述分析，不等式 \(\frac{x-1}{x+2} \leq 0\) 的解集为：

\[
(-\infty, -2) \cup [1, +\infty)
\]

即 \(x < -2\) 或 \(x \geq 1\)。
