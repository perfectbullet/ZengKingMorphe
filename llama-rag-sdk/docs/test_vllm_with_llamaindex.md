# test_vllm_with_llamaindex.py 使用文档

## 概述

本脚本用于测试 LlamaIndex + vLLM Embedding API 的集成，使用 LlamaIndex 官方的 `OpenAIEmbedding` 类连接 BGE-M3 vLLM 服务。

**vLLM 服务地址**: `http://192.168.8.233:8092`

## 依赖安装

```bash
# 激活虚拟环境
source /home/zj/miniconda3/envs/morphe/bin/activate

# 安装依赖
pip install llama-index-embeddings-openai
```

## 运行脚本

```bash
cd /home/zj/ZengKingMorphe/llama-rag-sdk
/home/zj/miniconda3/envs/morphe/bin/python examples/test_vllm_with_llamaindex.py
```

## 功能说明

脚本包含 4 个测试函数，可在 `main()` 函数中开启/关闭：

### 1. test_basic_embedding() - 基本嵌入测试

测试基本的文本嵌入功能，使用珐琅工艺相关的 5 个短文本。

**测试内容**:
- 珐琅是什么？
- 珐琅工艺的历史
- 釉料的成分
- 烧制温度
- 透明釉料的特点

### 2. test_long_text() - 长文本测试

测试不同长度的文本嵌入，验证模型处理长文本的能力。

**测试长度**: 100, 200, 500, 1000, 2000, 4000, 8000 字符

### 3. test_real_markdown() - 真实文档 + LlamaIndex 索引

使用真实的珐琅工艺 markdown 文档进行完整的 RAG 流程测试：

1. 读取 `data/sample_md/01珐琅工艺-16pages-part1-page1-16.md`
2. 按标题分割文档
3. 创建 ChromaDB 向量存储（host: 192.168.8.233, port: 8200）
4. 创建 LlamaIndex 索引
5. 测试 4 个查询的检索效果

**测试查询**:
- 什么是珐琅？
- 珐琅釉料由什么组成？
- 透明釉料有什么特点？
- 珐琅工艺的起源

**ChromaDB 集合名称**: `test_vllm_llamaindex_openai`

### 4. test_similarity() - 相似度计算

测试文本相似度检索和余弦相似度计算。

## 配置说明

```python
embed_model = OpenAIEmbedding(
    model_name="BAAI/bge-m3",
    api_key="not-needed",      # vLLM 不需要真实 API key
    api_base="http://192.168.8.233:8092/v1",
    embed_batch_size=32,
    timeout=300,
)
```

如需修改服务地址，更改 `api_base` 参数即可。
